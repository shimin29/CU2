# Local Storage vs Session Storage

## What is the difference?

Local storage will persist even after browser tab is closed, or even after the entire browser is closed.
That means it can store your login data, and the next time you visit the same page, you will automatically be logged in.

Session storage, is only for that session, meaning if you close the tab, you will be logged out and data will be lost.
